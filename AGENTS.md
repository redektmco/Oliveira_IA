# Oliveira IA

Aplicação React, TypeScript e Vite, com Supabase para autenticação/banco e funções Node na Vercel para Claude. Use o checkout existente; as tarefas já são isoladas, não crie worktrees sem solicitação.

Leia README.md e docs/DEPLOY.md. Execute `npm run typecheck`, `npm test` e `npm run build` após mudanças. `npm run dev` inicia frontend e API local. Nunca exponha chaves Anthropic, service role ou Vercel no frontend, em logs ou commits. Preserve o isolamento por usuário e as políticas RLS da migração Supabase.

O ZIP original era um protótipo Figma; seus scripts de Figma não representam a infraestrutura deste projeto. Não afirme conexões externas ou chamadas reais sem validação.
